# StreamLabs Token

> This is a simple react app that allows you to get a OAuth Token to use in [streamdevs/webhook](https://github.com/streamdevs/webhook)

You can get your own OAuth `client_id` and `client_secret` in the [StreamLabs developer console](https://dev.streamlabs.com/docs/register-your-application).
